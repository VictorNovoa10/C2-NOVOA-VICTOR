# Smart Events - Certamen 2

Sistema web para la gestión de eventos estudiantiles y culturales.

## Funcionalidades

- Ver eventos publicados.
- Mostrar título, fecha, hora, lugar, imagen, valor y cantidad de inscritos.
- Agregar eventos desde panel de administración.
- Registrar personas en un evento.
- Ver lista de inscritos por evento.
- Eliminar inscripciones.

## Tecnologías utilizadas

- Nuxt
- Vue
- TailwindCSS
- Prisma
- MySQL
